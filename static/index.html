Shared by every device. The Group by menu above the table can still change the grouping for a visit.

Spool labels

Shared by every device. After a change, each label is downloaded again the first time it's used (1 API request per label). Settings you've used before are still cached.

Filament labels

Made from one of your spools' labels, with the QR code changed to open the filament's page. Only properties that apply to any spool are offered.

Printer:

Saved on the server for each printer, and picked automatically when that printer connects. Changes save as you make them.

Offsets move the print as you read the label: positive is right or down, negative is left or up. One printer dot is 0.125 mm.

The outer border is the label's edge and the inner one is 1 mm in, with ticks every 1 mm. If the print sits to the right, use a negative horizontal offset, and so on, until the border is even. This uses no API requests.
